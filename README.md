# Haverbex — site

The built static site of Haverbex.

*   Company page: https://topabaem05.github.io/eg2-ko-reader-demo/
*   EG2-KO Reader (a Korean speech-to-text reader on top of the EmbeddingGemma 2 audio
    encoder): https://topabaem05.github.io/eg2-ko-reader-demo/eg2-ko-reader/
*   Model: https://huggingface.co/Haverbex/eg2-ko-reader
*   Demo Space: https://huggingface.co/spaces/topabaem/eg2-ko-reader-demo

This repository holds only the built static files (HTML, JavaScript, CSS, fonts and a small
WebAssembly module). It was made with Vite, React, Tailwind, shadcn/ui, GSAP, heerich
(voxels, MIT) and dither-kit-rs (`dither-core` compiled to WebAssembly, MIT or Apache-2.0).
The fonts are Pretendard and Geist Mono (SIL Open Font License 1.1).

Commercial use of the model by organizations: guritopabaem@gmail.com, subject starting with
`[Commercial]`.
